# Devine le nombre

Un petit jeu dans le navigateur : l'ordinateur choisit un nombre entre 1 et 100,
et tu dois le deviner. Il te dit à chaque fois « plus » ou « moins ».

## Lancer le jeu

Ouvre simplement `index.html` dans ton navigateur.

## Fichiers

- `index.html` : la structure de la page
- `style.css` : l'apparence
- `script.js` : la logique du jeu

Projet créé pour apprendre Git et GitHub.
